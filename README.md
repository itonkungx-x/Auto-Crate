# Auto-Crate

Fabric client-side Minecraft 26.3 mod for ExcellentCrates reward automation.

The project includes a GitHub Releases auto-updater, MMO/SMP profile isolation, and local crate presets. The auto-updater only installs releases from this repository and verifies SHA-256 before staging the mod for replacement **after Minecraft exits**.

> To enable unauthenticated in-game release checks, set this repository to **Public** under GitHub Settings > General > Danger Zone > Change repository visibility. It is currently private. No GitHub personal access token is embedded in the mod.

See the releases page for downloadable builds when the first release workflow succeeds.
